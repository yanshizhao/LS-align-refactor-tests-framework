# output_diff 用例清单
#
# 每行： name | workdir(相对 tests/；"." 即 tests/) | args | mode
#   - mode = exact         : 当前输出必须与 baseline 逐字节一致（业务数据不变）
#   - mode = expected:KEY  : 输出允许变化，但须符合 expected/KEY.json 的期望（R 批会改数值项）
#
# 说明：
#   * 只登记"需要输出级逐字节比对"的用例；单元/CLI 断言不在此列（见 unit/、cli/）。
#   * stdout 与 stderr 分开记录、分开比对：baseline/<name>.out / .err，
#     current/<name>.out / .err，差异分别落到 diffs/<name>.out.diff / .err.diff。
#     因此诊断进 stderr（B27）后，结果表仍在 .out 里逐字节比对。
#   * 数据位置：共用数据在 output_diff/data/，本用例独有数据在 output_diff/data/；
#     args 里写相对 tests/ 的显式路径，从哪里取数据一眼可见。
#   * 制动模式(-rf 0)确定性最好；柔性(-rf 1)含 rand() 抽样，仅在确定性可控时纳入。
#
# 格式： name                     workdir  args(相对 workdir)                                          mode
ace_rigid                 .    output_diff/data/ace_ligands.mol2 output_diff/data/xtal-lig.mol2 -rf 0             exact
self_copy                 .    output_diff/data/self.mol2 output_diff/data/copy.mol2 -rf 0                        exact
octane_self               .    output_diff/data/octane.mol2 output_diff/data/self.mol2 -rf 0                      exact
tiny_octane               .    output_diff/data/tiny.mol2 output_diff/data/octane.mol2 -rf 0                      exact
shorter_octane            .    output_diff/data/shorter.mol2 output_diff/data/octane.mol2 -rf 0              exact
unrelated                 .    output_diff/data/unrelatedA.mol2 output_diff/data/unrelatedB.mol2 -rf 0            exact
octane_octane             .    output_diff/data/octane.mol2 output_diff/data/octane.mol2 -rf 0                    exact
self_self                 .    output_diff/data/self.mol2 output_diff/data/self.mol2 -rf 0                        exact
isolated_rigid            .    output_diff/data/isolated_atom.mol2 output_diff/data/tiny.mol2 -rf 0               exact
ace_flex                  .    output_diff/data/ace_ligands.mol2 output_diff/data/xtal-lig.mol2 -rf 1             exact
octane_flex               .    output_diff/data/octane.mol2 output_diff/data/self.mol2 -rf 1                      exact
